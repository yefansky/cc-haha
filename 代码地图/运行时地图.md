## 子 Agent 和 fork 特有进度链

恢复路径也要辨别占位文件：`src/services/compact/reactiveCompact.ts:1` 是 generated stub，不能因为名字或上游恢复图就承诺当前可用。上表的 Auto Compact 是另一条有实际代码的路径。

原始设计入口是 `src/tools/AgentTool/AgentTool.tsx`：`:292` teammate，`:514` fork 消息，`:695` async 注册，`:855` `runAgent`。`src/tools/AgentTool/runAgent.ts:529` 解析子工具池，`:791` 复用核心 `query()`。四条路径不是所有发行入口都默认可用。

`src/tools/AgentTool/forkSubagent.ts:32` 的 `isForkSubagentEnabled` 要求 `FORK_SUBAGENT` 且排除非交互会话；桌面 `--print` 不应按默认 fork 前缀缓存路径理解。

当前工作区额外增加长思考/流式进度通道：

```text
runAgent 先观察 stream_event
  → agentStreamProgress 发布进度
  → sdkEventQueue 订阅
  → print 独立 drain，不等父生成器再次 yield
  → handler 转译 agent_stream_progress
  → chatStore / 子代理展示
```

证据：`src/tools/AgentTool/runAgent.ts:783`、`src/tools/AgentTool/agentStreamProgress.ts:14`、`src/utils/sdkEventQueue.ts:116`、`src/cli/print.ts:1939`、`src/server/ws/handler.ts:4267`。其中 `agentStreamProgress.ts:27` 的 token 数是字符数 / 4 的估计，不是服务商计费 usage。
