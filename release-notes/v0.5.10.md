# Claude Code Haha v0.5.10

## 剑网3项目定制版更新

- 桌面端自动更新在运行时固定读取 `yefansky/cc-haha` 的 GitHub Release，不依赖安装包内旧的更新源配置。
- 关于页明确显示当前已安装版本，并标注更新源为 `yefansky/cc-haha`。
- 保持 Windows NSIS 自动更新链路：下载完整安装器后自动退出、安装并重启，无需手动重复安装。

## 发布要求

- 发布 tag 必须为 `v0.5.10`，并上传 Windows 安装器、对应 `.blockmap` 与 `latest.yml`。
- 首次从旧版 `42.7.0` 迁移时，需手动安装 fork 的 `v0.5.9` 安装器；之后版本可通过 fork 的自动更新链路升级。
